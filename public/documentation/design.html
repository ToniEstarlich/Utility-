Utility
Documentation Architecture
Design System

Simple by design.

Utility uses a quiet, modern interface designed to make small tasks feel fast, clear, and effortless.

Color palette

Background #EDF1F0
Text #111615
Text Soft #4F5855
Muted #7C8582
Accent #DFFF45

Typography

One place for every little task.

Typography is clean, compact, and confident. Large headings use tight letter spacing while supporting text remains soft and readable.

Visual language

Utility combines glassmorphism and subtle neumorphism. Surfaces are translucent, borders are soft, and shadows create depth without making the interface feel heavy.

The lime accent is intentionally used sparingly. It identifies important actions, highlights, and moments of interaction.

Writing style

Clear Use direct language and avoid unnecessary technical wording.
Short Explain what the tool does in as few words as possible.
Helpful Tell users what to do next instead of overwhelming them with information.
Human Utility should feel like a useful product, not a technical dashboard.
